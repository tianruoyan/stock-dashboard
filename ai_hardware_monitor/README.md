# AI硬件二次启动雷达 V1.0

## 1. 产品定位

本模块把“等待资金确认后再关注”的交易研究逻辑转成可重复运行、可审计的盘中观察模型。它是 V2/V2.2 决策系统的专题投影，不是第二套真相源，也不执行下单、持仓修改、模型晋级或收益承诺。

固定检查点：09:35、10:30、14:30（Asia/Shanghai）。

固定股票池：

| 分组 | 股票 |
|---|---|
| CPO / 光模块 | 新易盛、中际旭创、天孚通信 |
| PCB | 沪电股份、胜宏科技、生益科技 |
| AI 网络 | 锐捷网络、盛科通信 |

V1 使用上述 8 只股票的等权涨跌幅作为“AI硬件代理篮子”。它不是交易所或数据商发布的官方板块指数，页面必须明确标注这一点。

## 2. MVP 范围

V1 已包含：

- 100 分评分：板块强度 30、龙头强度 30、资金回流 20、市场环境 20。
- 三态输出：🟢启动、🟡观察、🔴风险。
- 绿色状态硬门槛：总分、板块排名、龙头领先、量能、资金连续性、数据完整度必须同时满足。
- 09:35、10:30、14:30 三个检查点识别。
- 09:40-11:25、13:05-14:50 盘中即时触发巡检，满足共振条件时写入提醒并弹出本机通知。
- 原子写入当前状态、运行历史和状态变化提醒。
- 独立静态页面，并从 V2 首页进入。
- 实时采集器：腾讯公开行情用于当日价格/成交，新浪公开日 K 用于 5/10 日趋势及成交速度基线，V2 已治理市场环境用于环境约束。
- 标准化 JSON 输入模式，供后续接入正式板块排名、ETF 份额/资金和授权数据源。

V1 暂不包含：

- 自动交易、自动调仓或券商接口。
- 手机、短信、邮件、企业微信等外部通知通道；V1只使用本机macOS通知中心。
- 未经授权的“主力资金”推断。
- 龙虎榜席位、北向资金、融资余额、美股联动自动评分。
- 用历史回测命中率自动调权。

## 3. 数据来源与字段

| 数据 | V1 来源 | 关键字段 | 缺失处理 |
|---|---|---|---|
| 个股实时行情 | 腾讯财经公开行情 | price、change_pct、volume、amount_yi、quote_as_of | 对应股票不参与聚合，并降低覆盖率 |
| 5/10 日趋势 | 新浪财经公开日 K | close、volume、day | 不计算该股均线与成交速度 |
| 沪深300基准 | 腾讯财经公开行情 | benchmark_change_pct | 板块相对强度记为缺失 |
| 市场环境 | V2/V2.2 已治理环境快照 | liquidity、breadth、sentiment | 只读取同交易日证据；旧数据不复用 |
| 可比行业排名 | 腾讯财经 98 个行业指数 | sector.market_rank | 8股代理篮子与行业指数比较；不冒充官方主题排名 |
| 股票池资金 | 东方财富公开资金流 | continuous_net_inflow_days、pool_net_inflow_yi | 8股汇总；部分股票缺失时降级 |
| ETF流向 | 标准化上游快照 | etf_net_inflow_yi | V1 未指定ETF篮子，保持缺失，不用成交额推断 |

标准化输入见 `config/input-contract.json`。所有事实都要携带交易日、时点、来源和质量状态；旧交易日数据不能作为当前机会。

## 4. 评分规则

### 板块强度（30）

- 代理篮子相对沪深300：最高 15 分。
- AI硬件8股代理篮子在腾讯可比行业指数中的排名：最高 8 分。
- 8 股上涨宽度：最高 7 分。

### 龙头强度（30）

核心龙头为新易盛、中际旭创、沪电股份。

- 龙头强于代理篮子：最高 10 分。
- 龙头成交速度相对 5 日同时点基线：最高 10 分。
- 龙头站上 5 日与 10 日均线：最高 10 分。

### 资金回流（20）

- 连续净流入天数：最高 10 分。
- 8股股票池公开资金净流入：5 分。
- 相关 ETF 净流入：5 分。

资金字段必须来自可核验上游；V1 不把放量等同于净流入。

### 市场环境（20）

- 两市成交相对基线：最高 8 分。
- 科技股上涨宽度：最高 6 分。
- 涨跌停强弱比：最高 6 分。

## 5. 状态与提醒

- `🟢启动`：总分 >= 80，且数据覆盖率 >= 80%、板块市场前三、至少一只核心龙头领先、龙头成交速度 >= 1.2、连续资金净流入 >= 2 天。
- `🟡观察`：40-79 分；或虽然 >= 80 分但任一绿色硬门槛未满足；或数据不足/过期。
- `🔴风险`：在数据覆盖率 >= 65% 且数据有效的前提下，总分 < 40。

盘中即时提醒与绿色状态分开：评分>=60、覆盖率>=65%、可比行业前三、相对沪深300超额>=1%、上涨宽度>=70%、核心龙头领先且成交速度>=1.2倍时，触发一次“🟠盘中候选”本机通知。候选只提示提前核验，不替代10:30或14:30固定确认。

“评分 >= 80”只触发买入观察，不等于买入指令。提醒仅在检查点首次运行或状态变化时写入，最终行动由用户决定。

## 6. 目录

```text
ai_hardware_monitor/
├── config/       股票池、权重、阈值、检查点、数据源与输入契约
├── data/         当前快照、状态、提醒与历史
├── engine/       采集、评分、提醒和运行编排
├── dashboard/    专题雷达页面
└── tests/        评分、状态门槛、检查点与页面契约测试
```

## 7. 运行

从项目根目录执行：

```bash
python3 scripts/run_ai_hardware_monitor.py --live
```

安装本机检查点服务（部署到现有 V2 本地运行目录后加载；不接外部通知、不自动交易）：

```bash
zsh scripts/install_ai_hardware_monitor.sh
```

用标准化快照重放或测试：

```bash
python3 scripts/run_ai_hardware_monitor.py --input ai_hardware_monitor/data/input-snapshot.json --force-checkpoint
```

页面入口：`ai_hardware_monitor/dashboard/ai_hardware.html`。

## 8. 与现有工作台的兼容边界

- 读取 V2 已治理市场环境，不覆盖 V2 决策案例、股票池、持仓或模型注册表。
- 输出只写入 `ai_hardware_monitor/data/`。
- 不修改 V1 页面与生产通知。
- 不进入统一发布器，除非后续单独完成发布白名单与数据隐私审计。
